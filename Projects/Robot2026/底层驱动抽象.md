# 底层驱动抽象

## 0. `MySystem`

```c
// 1. 芯片底层驱动
#include "main.h"   // 主函数
#include "stdint.h" // 整形数据使用
#include "gpio.h"   // GPIO
#include "tim.h"    // 定时器
#include "usart.h"  // 串口
// #include "i2c.h"    // I2C
// #include "adc.h"    // ADC
// #include "dma.h"    // dma

// 2. 本地底层通用
#include "MyGPIO.h"
#include "MyPWM.h"
#include "MyEncoder.h"
#include "MyTimer.h"
```

+ 以此实现本地底层后续在其他芯片的通用化



## 1. GPIO

```c
// GPIO结构体定义
typedef struct 
{
    GPIO_TypeDef *GPIO_Port;
    uint16_t GPIO_Pin;
} MyGPIO_Typedef;
```

+ GPIO相关函数
  + GPIO写
  + GPIO读

## 2. PWM

```c
typedef struct
{
	TIM_HandleTypeDef* htimx ;
	uint32_t Channel ;
}MyPWM_Typedef ;
```

+ PWM相关函数
  + 初始化
  + 设置PWM值
  + 得到相关参数如PSC, ARR, 但是这些都不太常用, 所以后续可以忽略该部分的一般化

## 3. Encoder 

```c
typedef struct
{
	TIM_HandleTypeDef *htimx;
}MyEncoder_Typedef;
```

+ Encoder 相关函数
  + 编码器初始化
  + 得到编码器脉冲数



+ 注: 编码器有板载编码器也有外部触发编码器, 需要注意区分, 相关的代码不同之处不少, 如果是软编码(外部触发) , 需要自己配置原有结构体有两个GPIO即可



## 4. Timer(定时器)

+ 由于各个芯片的定时器不尽相同并且差异较大, 但是一旦配置完成就不用管了, 所以这里也是不建议使用一般化处理, 直接抽象出函数 : 

  + 初始化

  + 定时器对应的定时时间



+ .c

```c
// 定时器初始化
void Timer_Initial(void)
{
	HAL_TIM_Base_Start_IT(&htim16);
	HAL_TIM_Base_Start_IT(&htim17);
}

/*弱函数声明,主函数调用*/
__attribute__((weak)) void Timer_1ms_Callback(void)
{
    // 默认空实现
}

// 定时器回调函数
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  //判断是否是TIM17中断
  if (htim->Instance == TIM17)
  {
    Timer_1ms_Callback() ;	// 1ms中断
  }
}
```

+ .h 

```c
void Timer_Initial(void) ;
void Timer_1ms_Callback(void) ;
```
