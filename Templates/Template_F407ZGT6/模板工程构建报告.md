## 1. 任务与边界

本次以 `D:\github\HUST_STI\HUST_STI_1\Templete\Templete_STM32F407ZGT6` 为架构参考，以本目录 `README-F4.md` 为硬件范围依据。保留 `Mymain → Mode_G → Mode_1~6` 的 Setup、Loop、Tick、Exit 模式接口和模式切换顺序。没有引入 MySystem、AT24C02/参数保存、IMU、电机、屏幕串口屏等 README 未列出的设备或业务。

## 3. 启动与时序

1. `HAL_Init()` 初始化 HAL，TIM13 作为 HAL 的 1ms 时基。
2. `SystemClock_Config()` 配置 168MHz 系统时钟；APB1 定时器时钟为 84MHz。
3. `MX_GPIO_Init()`、`MX_DMA_Init()`、`MX_TIM6_Init()`、`MX_TIM7_Init()`、`MX_USART1_UART_Init()`、`MX_USART2_UART_Init()` 完成 CubeMX 外设配置。
4. `Mymain()` 调用 `Mode_G_Setup()`，先初始化 OLED，并让 Serial1/2 绑定 CubeMX 句柄、启动 DMA 空闲接收，再启动 TIM6/TIM7 中断，目标模式设为 Mode_1。
5. 主循环清 OLED 缓冲，运行全局模式逻辑；模式发生变化时依次调用原模式 Exit、目标模式 Setup，更新 `curr_mode`；其余循环运行当前模式 Loop，最后 `OLED_Update()` 刷屏。
6. KEY0 单击将目标模式推进一位；Mode_6 后回到 Mode_Null。无 EEPROM 模式记忆，复位后从 Mode_1 开始。

TIM6 预分频 84-1、周期 1000-1，对应 1ms。TIM7 预分频 84-1、周期 20000-1，对应 20ms。CubeMX 重新生成了 NVIC 配置；当前 TIM6/TIM7、USART1/2 和 DMA 的优先级由 `.ioc` 和生成代码控制。Mode2 的中断打印使用阻塞 UART 发送，实板上应确认发送正常。

## 4. Key 与 OLED HAL 适配

KEY0/KEY1/KEY2 分别读取 PE4/PF4/PF6，均为上拉、低电平按下。KEY_COUNT 调整为 3，删除无引脚对应的 KEY3。沿用参考按键状态机：每 1ms 更新计时，每 20ms 取样；双击判定窗口 200ms，长按阈值 1000ms。按键标志数组声明为 `volatile`，供中断和主循环共享；Key_Check 加入索引边界检查。

OLED 保留原有字库、图形函数和帧缓冲刷新方式，仅把 PB8/PB9 的 MyGPIO 写操作改为 `HAL_GPIO_WritePin()`。OLED 的四个低层电平调用已统一使用 `main.h` 的引脚宏；没有增加 I²C 外设。

## 5. 串口实现

CubeMX 生成的 `Core/Src/usart.c`、`dma.c` 配置 Serial1（USART1、PA9/PA10）和 Serial2（USART2、PA2/PA3），均为 115200 8N1。USART1_RX 使用 DMA2_Stream2，USART2_RX 使用 DMA1_Stream5；`Function/Serial_porting.c` 直接使用 `usart.h` 中的 `huart1/huart2`，只绑定实例、初始化协议常量并启动 `HAL_UARTEx_ReceiveToIdle_DMA()`。空闲帧由 MyISR 的 HAL 回调转入 `Serial_RxEventCallback()` 解析并重启接收，半传输回调已禁用。发送沿用阻塞 HAL UART。

参考工程 `Serial_porting.h` 的 17 个公开 `Serial_*` 函数名已全部保留，包括指针式 `Serial_printf(&Serial1, ...)`、原始字节/字符串发送、HEX 帧发送、ABC/HEX 新包标志/错误/数据读取、关键词与命令匹配、数值提取、清空和调试输出。`Serial_Agreement_ABC_Init()` 与 `Serial_Agreement_HEX_Init()` 位于 Serial_base。ABC 帧格式为 `@...$#`；HEX 帧格式为 `FF AA LEN (高字节 低字节 异或校验)×LEN 55 FE`。目前只启用 Serial1/Serial2；早先未列入硬件范围的 UART4 未配置。

`.ioc` 记录 USART1/2、PA9/PA10/PA2/PA3、两路 RX/TX DMA 和中断。GPIO、DMA、UART 句柄和 IRQ 都由 CubeMX 生成；Serial_porting 不再手写外设和 NVIC 初始化。上次手写的 4 个同名 IRQ 已删除，避免与生成代码重定义。

## 6. Mode_2 行为

`num` 初始为 1，类型为 `int`，保留于 Mode_2.c 的静态变量中。Mode_2 的 20ms Tick 内：

- KEY1 单击：`num *= 10`；达到 `INT_MAX / 10` 上界后不再乘，以免有符号整数溢出。
- KEY1 双击：`num /= 10`，使用 C 整数除法。
- KEY2 单击：`num = 0`。
- 随后执行 `Serial_printf(&Serial1, "%d\n", num)`，即每 20ms 从 Serial1 输出一次当前数值。

Mode_2 的 Loop 在 OLED 显示标题和 num。清零后，按规定执行乘法仍是零；重新烧录/复位可恢复初始值 1。KEY1 的单击需等待双击判定窗口结束，因此是松开后约 200ms 生效；双击在第二次按下时生效。
