# Template_F103C8T6 模板工程构建报告

## 1. 目标与依据

以 D:\github\2-2-STM32\STM32\Templates\Template_F407ZGT6 的现有模板为应用架构和串口 API 参考，以本工程 README-F1.md、.ioc 和 CubeMX 生成代码为 F103 的硬件配置依据。应用仅使用 README 中的 LED0、KEY0、KEY1、软件 OLED、USART1、USART2，以及 SysTick 1ms/20ms 时基。没有新增外设、按键、AT 保存逻辑或 MySystem。

## 2. 现有硬件映射

| 功能 | 引脚/外设 | 用法 |
| --- | --- | --- |
| LED0 | PC13 | 保留 CubeMX GPIO 配置 |
| KEY0 | PB12 | 上拉输入，低电平按下；单击切换模式 |
| KEY1 | PB13 | 上拉输入，低电平按下；Mode2 单击、双击、长按 |
| OLED SCL/SDA | PB8/PB9 | CubeMX 配置 GPIO，应用软件时序 |
| Serial1 | USART1 PA9/PA10 | 115200，CubeMX UART/DMA 句柄 |
| Serial2 | USART2 PA2/PA3 | 115200，CubeMX UART/DMA 句柄 |
| 时基 | SysTick | 1ms 中断；软件计数 20 次触发模式回调 |

F103 的 README 只有两只按键。用户明确指定不配置新按键，并将 Mode2 清零改为 KEY1 长按。

## 3. 文件结构和启动链

- Core/Src/main.c 在 MX_GPIO_Init()、MX_DMA_Init()、MX_USART1_UART_Init()、MX_USART2_UART_Init() 后调用 Mymain()，修改放在 CubeMX 的 USER CODE 块。
- Top/Mymain.c 保留 F407 模板的主循环、模式 Setup/Loop/Exit 派发和 OLED 更新方式。
- Mode/Mode_G.c 保留当前/下一模式及 KEY0 单击切换机制，默认下一模式为 Mode2。
- Mode/Mode_1 到 Mode_6 均保留 Setup/Loop/Tick/Exit 接口，其他模式暂为模板空实现。
- Top/AllHeader.c 初始化 OLED、两个串口接收，再调用 Initial_Timer() 启用应用 SysTick 回调。
- Tools/Timer_Counter.c/h 保留 F407 的 Cortex-M DWT 计时工具；没有配置独立定时器。

## 4. 中断与时基

CubeMX 的 SysTick_Handler() 先调用 HAL_IncTick()，随后在 USER CODE 块中调用 MyISR_SysTick()。此函数在应用初始化前直接返回；启用后每 1ms 调用 Key_Tick()，每 20ms 根据 curr_mode 调用对应 Mode_x_Tick()。没有添加 TIM 外设，也没有重定义 CubeMX 的 USART/DMA IRQ 函数。

MyISR.c 统一实现 HAL_UARTEx_RxEventCallback() 与 HAL_UART_ErrorCallback()，转交给串口模块。这样中断入口仍集中可查，IRQ 所有权也与 CubeMX 生成代码一致。

## 5. 外设与 API

### Key

Hardware/Key.c/h 只扫描 KEY0、KEY1。保留 F407 模板的 HOLD、DOWN、UP、SINGLE、DOUBLE、LONG、REPEAT 事件 API 和 20ms 消抖/判定状态机。KEY1 长按阈值沿用模板的 1000ms。

### OLED

Hardware/OLED.c/h、OLED_Data.c/h 保留显示、格式化打印、绘图和字库 API。底层使用 HAL_GPIO_WritePin 控制 PB8/PB9，不自行重新配置 GPIO。

### Serial1 和 Serial2

Function/Serial_porting.c/h、Hardware/Serial_base.c/h 保留 F407 模板的两串口结构和 API，包括：

- Serial_Init、Serial_printf、Serial_SendBytes、Serial_send_string、Serial_PrintDebug
- ABC 协议的命令比较、关键词查找、整数/浮点解析、错误与新包查询、清空
- HEX 协议发送、数据/长度、错误与新包查询
- DMA 接收至空闲事件及错误恢复回调

初始化直接使用 CubeMX 生成的 huart1、huart2，不重复写 UART GPIO、波特率或 DMA 通道配置。串口中断由生成文件交给 HAL 处理。

## 6. Mode2 具体行为

Mode2 初始 num = 1。KEY1 单击乘 10（超过 INT_MAX 前停止增长），双击除 10，长按清零。OLED 显示当前整数，不在显示过程中隐式递增。Mode2 的 20ms 中断回调执行 Serial_printf(&Serial1, "%d\n", num)。KEY0 单击仍切换模式。

- AXF/HEX：MDK-ARM/Template_F103C8T6/

验证覆盖编译、链接、HEX 生成、HAL API 与 IRQ 符号兼容性。尚未连接实际 STM32F103C8T6 板卡，按键电平、OLED 显示和物理串口收发仍需上板验证。

## 8. 后续维护注意

在 CubeMX 中调整 .ioc 后重新生成代码时，保留 main.c 和 stm32f1xx_it.c 的 USER CODE 块，并检查 Keil 工程中的应用分组及 IncludePath。HAL 生成的 IRQ 函数应保持唯一；应用逻辑只放 MyISR.c 回调中。F103 只有两只按键，Mode2 的 KEY1 长按清零是针对本板的既定映射。
